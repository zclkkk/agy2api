# agy2api v0.1.0

首个版本，将单个 Antigravity 账号的 Gemini 订阅接入 OpenAI Responses / Images 和 Anthropic Messages API。

## 功能

- 流式与非流式生成、工具调用、思考回放和 token 计数。
- 图片、PDF、音视频文件输入。
- 独立 Images API 的图片生成与编辑，支持批量图片、文件上传和 Base64 返回。
- Responses 历史续聊和上下文压缩。
- 授权码回填登录、凭据自动刷新、TOML 配置和 API Key 访问控制。

## 发布包

提供 Linux、macOS 的 amd64/arm64 版本，以及 Windows amd64 版本。采用原生单文件程序部署，附带配置示例、用户文档、许可证和 SHA-256 校验和。

## 限制

仅支持单账号和 Gemini 模型，不提供原生网页搜索。Images 仅提供非流式生成与编辑，尺寸和输出选项见 API 文档。严格 JSON Schema、精确停止序列元数据和可见思考内容受上游能力限制。模型可用性及额度由账号决定。
